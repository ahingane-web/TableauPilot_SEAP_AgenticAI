2. Dashboard flow (end to end)

From unlocking the vault to a verified, published dashboard you refine in the real embed.

sequenceDiagram
    autonumber
    actor User
    participant SPA as Browser SPA
    participant BFF as Hono BFF
    participant Vault as PIN Vault + Session
    participant Agent as Mastra Agent + Workflow
    participant LLM as LLM Gateway
    participant Tableau as Tableau Cloud

    Note over User,Vault: A. Identity and secrets
    User->>SPA: Enter username + 6-digit PIN
    SPA->>BFF: POST /api/vault/unlock
    BFF->>Vault: Derive key, decrypt creds into session
    Vault-->>BFF: sessionId (opaque)
    BFF-->>SPA: sessionId

    Note over User,Tableau: B. Connect and lock a datasource
    SPA->>BFF: POST /api/tableau/connect
    BFF->>Tableau: REST sign-in with PAT
    SPA->>BFF: GET projects and datasources
    User->>SPA: Pick project + datasource
    SPA->>BFF: select-project and lock-datasource
    BFF->>Tableau: Fetch datasource metadata (real fields)
    BFF-->>SPA: Locked datasource + field list

    Note over User,LLM: C. Plan (AI) and approve
    User->>SPA: Describe the dashboard
    SPA->>BFF: POST /api/dashboard/plan
    BFF->>Agent: Plan against real fields
    Agent->>LLM: Prompt with field metadata
    LLM-->>Agent: Draft plan
    Agent-->>BFF: Zod-validated DashboardPlan
    BFF-->>SPA: Plan for review
    User->>SPA: Approve
    SPA->>BFF: POST /api/dashboard/approve

    Note over BFF,Tableau: D. Execute, publish, verify
    SPA->>BFF: POST /api/dashboard/execute
    BFF->>Agent: Generate .twb from plan
    Agent->>Tableau: Publish workbook (REST)
    Agent->>Tableau: Verify it exists (REST/Metadata)
    Tableau-->>Agent: Real workbook id + URL
    Agent-->>BFF: Verified result
    BFF-->>SPA: Real Tableau URL

    Note over User,Tableau: E. Refine in the real embed
    SPA->>BFF: GET /api/embed/info
    BFF-->>SPA: Short-lived embed JWT or interactive login
    User->>SPA: Edit in Web Authoring embed
    SPA-->>User: WorkbookPublished events on save

3. Connector build flow

Building a live or extract datasource, then rejoining the dashboard flow above.

flowchart TB
    Start(["Build datasource in SetupPanel"]) --> Pick{"Which connector?"}
    Pick -->|Salesforce| SFconn["connect - list objects"]
    Pick -->|Excel| XLupload["upload .xlsx - parse sheets"]
    Pick -->|BigQuery| BQoauth["Google OAuth - project / dataset"]
    Pick -->|Data Cloud| DCconn["OAuth CDP + a360 - data space / objects"]
    Pick -->|Snowflake| SFwh["session login - warehouse / database / schema"]
    SFconn --> Model["DataModelBuilder - relationships or joins"]
    XLupload --> Model
    BQoauth --> Model
    DCconn --> Model
    SFwh --> Model
    Model --> Mat{"Live or Extract?"}
    Mat -->|Live BQ / DC / Snowflake| LiveTds["Generate bare .tds"]
    Mat -->|Extract all connectors| ExtTds["Generate .tds + .hyper sidecar"]
    LiveTds --> PubLive["Publish .tds"]
    ExtTds --> PubExt["Publish .tdsx"]
    PubLive --> Cred["Embed connection credential"]
    PubExt --> Cred
    Cred --> Refresh{"Extract?"}
    Refresh -->|yes except Excel| Now["refreshDatasourceNow best-effort"]
    Refresh -->|Excel / Live| Skip["no refresh"]
    Now --> Lock["Lock published datasource"]
    Skip --> Lock
    Lock --> Done(["Continue to dashboard flow"])
